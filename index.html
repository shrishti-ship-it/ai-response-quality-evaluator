    Evaluation framework

    This prototype uses five dimensions, each scored from 0 to 5.

    • Relevance: Does the answer address the task?
    • Completeness: Does it appear sufficiently developed?
    • Instruction-following: Does it respect apparent constraints?
    • Evidence quality: Can claims be compared with supplied reference text?
    • Safety: Does the response contain obvious warning signs?

    These are heuristic checks, not a validated measure of response quality or a substitute for human review.
